In Linux/Unix  everything is a file. 

In mac which is based on unix, it inherits everything is a file but also adds proprietary layers on top.

In windows everything is an object, where handles are universal interface.


## Utilities

- echo - printing text to the terminal, formatting and substituting variables. 
- man - show the manual of different commands 

## File management

- mkdir - make directories
- touch - create new files
- cat - concatenate files and print
- cp - copy files and directories
- mv - move files
- rm - remove files
- rmdir - remove folder
- tree - visualize directory structure
