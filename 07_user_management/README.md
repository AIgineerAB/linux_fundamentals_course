## Admin privileges

When installing a Oracle Linux, you can choose to disable root user by default, which is good practice to do. However some commands require root privileges, and the first user created on the system is allowed to use `sudo` command by default. With sudo you elevate the privileges to superuser privileges, which means there are many commands and many files that you can view and configure that a normal user can't.
